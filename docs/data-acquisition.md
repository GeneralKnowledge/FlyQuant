# Dataset acquisition and provenance

FlyQuant does **not** redistribute the raw FlyWire CSV release. Large datasets
must be obtained legally by the user.

## FlyWire FAFB v783 (primary connectome)

| Field | Value |
|---|---|
| Portal | https://codex.flywire.ai/api/download |
| Version | 783 |
| Licence | **CC BY-NC-SA 4.0** |
| Account | Free FlyWire account required; accept data terms at https://flywire.ai |

### Minimum files

```
neurons.csv.gz
classification.csv.gz
consolidated_cell_types.csv.gz
connections_princeton.csv.gz
coordinates.csv.gz
column_assignment.csv.gz
labels.csv.gz
visual_neuron_types.csv.gz
```

Set:

```bash
export FLYWIRE_V783_DIR="/path/to/FlyWire Brain Dataset (FAFB v783)"
```

Then, inside the submodule:

```bash
cd reference/fruit-fly-lab
python -m brain.connectivity.build_connectome
python -m pytest tests/test_data_provenance.py -q
```

SHA-256 expectations are recorded in
`reference/fruit-fly-lab/data/metadata/flywire_v783_checksums.txt`.

## Path used by FlyQuant without Codex login

The upstream repository commits browser assets under `web/data/`:

- `connectome.bin` — full CSR with delta-coded indices and int16 synapse counts
- `neurons.bin` — root IDs, positions, type codes, signs
- `meta.json` — string tables, receptive fields, modality metadata

FlyQuant’s `connectome_source: web` loader reconstructs a Python `Connectome`
from these files. This is still FlyWire-derived data under CC BY-NC-SA 4.0.
Do not treat redistribution of those binaries as public-domain.
